Do this first: point your downloads at Orch

Orch only sees files that land in the folder it's watching. Set that folder as the default save location everywhere, once, and every download sorts itself from then on.

Settings, then Downloads. Turn off "Ask where to save each file before downloading" and set the location to your Downloads folder (or whichever folder you set in Orch's Settings page).

Settings, then General, then Files and Applications. Under "Downloads," choose "Save files to" and pick the same folder.

Check its own Settings for a "Save to" or "Download location" option, and point it at the same folder. Most apps that download files let you change this somewhere in their settings.

Already set up? You can change which folder Orch watches anytime from Settings.
