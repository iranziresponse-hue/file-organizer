How Orch works

  • A profile is one context (School, Work, Research...) with its own folder and rules. Only one is active at a time.
  • Files matching a subject code or topic keyword route straight into that subject's folder.
  • No match? Optional AI fallback, then _Unsorted.
  • Media, installers, archives, and sensitive files sort automatically, no profile needed.
  • Switch or edit profiles anytime from Profiles. Watch folders live in Settings.
