How Orch works

Orch does two things: it keeps your files sorted automatically, and it turns everything it sorted into tools that help you study, track your career, and build a portfolio.

1. Sorting your files

  • Orch watches your Downloads folder (and an optional second folder), set in Settings. Any new file that shows up there gets moved automatically.
  • Some file types always go to the same place, no matter what. Orch creates these folders itself the first time it needs one:
    • Passwords, keys, and certificates → Documents\Personal\Important
    • Ebooks → your Library inbox, Documents\Personal\Library\00 New - Sort Me by default (you can change this in Settings)
    • Photos, music, and video → Documents\Personal\Media\...
    • Zip and rar files → Documents\Personal\Archives
    • Installers (.exe, .msi, .apk) → Documents\Personal\Installers
    • Code and project files → Documents\Work\_Unsorted
  • Everything else, like PDFs, Word docs, Excel sheets, and slides, is sorted by whichever profile is currently active. A profile is just one folder plus two labels you pick, usually something like Year and Semester.
  • Orch tries a few ways to figure out where a file belongs: first a subject code in the filename, then keywords that match a subject's topics, and if Smart Orch (the AI helper) is turned on, one last smart guess. If nothing matches, the file goes into that profile's own _Unsorted folder, sitting right next to the real subject folders so it's easy to find and move later.
  • No profile active yet, or a file type Orch doesn't recognize? It goes to Documents\Personal\_NeedsSorting so it's never lost.
  • Orch put something in the wrong place? Every row in the dashboard's Recent Moves table has a Move button so you can send it somewhere else yourself.
  • Want to double-check before a file moves? Decision Inbox holds anything Orch wasn't fully sure about, so you can approve it, send it somewhere else, or ignore it. Folder Rules let you build your own sorting rules without writing anything technical. Undo reverses any move, and Recent Moves now has a Clear history button if the list gets too long (this also removes the option to undo those particular moves).
  • Already have a messy folder from before you started using Orch? Folder Imports looks through it and suggests subjects and rules, then only touches anything once you say yes.

2. Studying with what's sorted

  • Study builds a memory of each subject from your sorted files: the topics it's noticed, the areas you're weak in, and a review queue that reminds you to revisit things before you'd naturally forget them.
  • Resource Radar finds real videos, books, and GitHub repositories related to your weak areas, never a made-up link. Learning Routes turn one weak area into a simple sequence: find a resource, read a short summary, review it, then check how confident you feel.
  • Any document can get an AI-written study summary if Smart Orch is turned on. Digests give you a recap of the week. Knowledge Packs export a subject, or your whole profile, as one portable bundle you can keep or share.

3. Career and portfolio

  • The Career tab is a command center: your current semester, the projects you're building, your career track and weekly goal, and a suggested next action.
  • Projects is where you track things you're building, from idea to finished, and turn them into portfolio evidence.
  • Resource Radar also recommends real GitHub repositories related to your course units, so you have something concrete to build on or learn from.
  • Write a post about your work as a draft, polish it with Smart Orch if you want, then publish it straight to GitHub (as a real commit) or a custom website you control, or export it as Markdown or HTML to post anywhere else yourself. Career Digests recap your career activity the same way study Digests do.

4. Staying connected

  • Connections is one page listing every outside service Orch can use: what's already connected, what you can add, and why each one is worth setting up.
  • Makerere students get real, sourced course units during setup, and can connect MUELE (to pull in course files and deadlines), a timetable, cloud backups, GitHub, and publishing channels, all from this one page.
  • Orch never stores a password for any of these. It only ever uses the service's own official sign-in (OAuth or an API key you provide), and you can disconnect at any time.

5. Staying on top of things

  • Notifications keeps a permanent record of deadline warnings, MUELE sync results, and anything else Orch has alerted you about, even if you missed the popup. Mark everything as read, or use Clear all if the list gets too long.
  • Memory shows the sorting rules Orch has learned from your own corrections over time, so you can see (and edit) exactly why it makes the decisions it makes.

6. Managing it all

  • Create, switch, or edit a profile from Profiles. Change which folders get watched, where ebooks land, or turn Smart Orch on or off, from Settings.
