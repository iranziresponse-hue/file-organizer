How Orch works

  • Orch watches two folders, set in Settings: your Downloads folder, plus an optional second one.
  • Every new file is checked against these first, in order: passwords, keys, and certificates go to Important. Ebooks go to your Library inbox. Photos, music, and video go to Media. Zip and rar files go to Archives. Installers go to Installers. Code files go to Work.
  • Everything else (PDF, Word, Excel, PowerPoint) is routed by whichever profile is currently active. A profile is one folder plus a pair of labels you choose, like Year and Semester.
  • Inside that profile: a subject code in the filename wins first. No code? Orch checks the filename against that subject's topic keywords instead. Neither matches, and smart fallback is enabled? Orch makes one last route suggestion. Still nothing? The file goes to that profile's own _Unsorted folder.
  • No profile is active yet, or the file type isn't handled above? It lands in Documents\Personal\_NeedsSorting so nothing gets lost.
  • Create, switch, or edit a profile from Profiles. Change which folders get watched, or where ebooks land, from Settings.
