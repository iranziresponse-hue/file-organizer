Get Orch for your Windows laptop.

Start with the folder you already use most: Downloads, a semester folder, or a project folder. Orch can help organize new files there, then you can add more support as your work grows.

Current version

Orch.exe

Use this file if your laptop runs Windows 10 or Windows 11.

Get Orch for Windows
  • About 225 MB
  • No account required to start
  • Best started with one folder you already trust

After you open Orch

  • Create a profile for school, online courses, research, work training, or projects.
  • Choose the folder where new files usually arrive.
  • Review files when Orch is not confident about where they belong.
  • Use Recent Moves when you need to check or undo a change.
Setup choices

Choose the setup that matches your work

Orch can begin with simple file organization. Classes, deadlines, revision tools, projects, and backups can be added later when they are useful.

For Makerere University students

Use the guided setup for college, school, programme, year, semester, and course units. MUELE and timetable support can be added when you want them.

For other study or work

Create your own profile labels, subjects, folders, and rules. Orch can still help with online courses, research, work training, and personal projects.

For careful sorting

Use review mode first. You can approve files, choose another folder, undo recent moves, and clear history when it is no longer needed.
