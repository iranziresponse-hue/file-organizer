Download for Windows
Downloads

Download Orch and start with one folder.

Orch is a free Windows app. You can begin with your Downloads folder, one semester folder, or one project folder, then add more only when it helps.

Current Windows app

Orch.exe

Use this if you are on Windows 10 or Windows 11 and want the normal desktop app.

Download Orch
  • About 225 MB
  • No account required to start
  • Works best when you choose a folder you already use

What happens after download

  • Open the app like a normal Windows app.
  • Create a profile for school, online courses, research, work training, or projects.
  • Choose the folder Orch should watch.
  • Let unsure files wait for review instead of moving them blindly.
Before you start

Pick the setup that matches your real work

You do not need to turn on every part of Orch. Start with file sorting, then bring in classes, deadlines, revision, projects, or backups later.

For Makerere students

Use the guided setup for college, school, programme, year, semester, and course units. MUELE and timetable support can be added when you want them.

For other study or work

Create your own profile labels, subjects, folders, and rules. Orch can still help with online courses, research, work training, and personal projects.

For cautious users

Use review mode first. You can approve files, move them elsewhere, undo recent moves, and clear history when it is no longer useful.
