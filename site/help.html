Help notes

What to do in Orch, without the technical noise.

These notes explain the parts most users need: setup, sorting, review, deadlines, study tools, projects, and where to ask for help.

First setup

Start by creating a profile. A profile is just a place for one kind of work, such as school, online learning, research, work training, or projects.

  • Makerere students can use the guided setup.
  • Other users can make their own labels and subjects.
  • Choose the folder Orch should watch for new files.

When files arrive

Orch checks new files from the folders you chose. It looks at names, course codes, file types, and rules you taught it.

  • Confident files can be sorted for you.
  • Unclear files wait for your review.
  • Every move leaves a record.

Decision Inbox

This is where Orch places files it should not move without you. You can approve the suggestion, pick another folder, ignore it, or clear the row.

Recent Moves and Undo

Use Recent Moves to see what changed. If a file went to the wrong place, use undo or move it somewhere better.

Settings

Settings is where you change watched folders, extra folders, sorting behavior, and optional helpers. If Orch says something needs setup, start there or use the setup checklist.

Profiles

Use profiles to keep different work separate. One profile can be for school, another for research, and another for a project or online course.

School and study

Use the study pages when files need context

Sorting is only the start. Orch also gives you pages for subjects, reviews, assignments, exams, and study plans.

Subjects

Each subject can collect files, summaries, topics, assignments, resources, and review items.

Reviews

Create review items from files or topics, then mark them done as you revise.

Assignments and exams

Track deadlines, add your own dates, and see what is coming up before it becomes urgent.

MUELE

Makerere students can connect MUELE to bring course files and assignment dates into Orch.

Timetable

Use your timetable group when available, or add your own class, test, or exam entries.

Exports

When you need a copy of one subject or profile, export a bundle with useful files and notes.

Projects and career proof

Project Studio is for work you may want to show later. Add the project name, what problem it solves, links, folder path, lessons learned, and updates. Orch can help turn that work into a weekly record or draft post when you choose.

When something feels wrong

  • Check the setup checklist if Orch says a feature is not ready.
  • Look at Recent Moves if a file is missing.
  • Use Decision Inbox if Orch is waiting for your choice.
  • Use Support below if a course, page, or action still does not make sense.
